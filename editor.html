06 · Page Studio

Конструктор всех страниц.

Выбирай страницу, перетаскивай блоки, скрывай, редактируй, добавляй текст, фото и цитаты. Preview показывает черновик. Publish сохраняет его в Supabase.

07 · Workflow

Редактируй → Preview → Publish.

Сначала меняй данные. Потом нажимай Preview внутри Page Studio. Если всё выглядит правильно, нажимай Опубликовать. GitHub отвечает за код, Supabase за контент.
