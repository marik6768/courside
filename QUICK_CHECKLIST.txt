COURTSIDE CLOUD CMS — QUICK CHECKLIST

1. Create a Supabase project.
2. Open SQL Editor and run supabase.sql.
3. Create your admin account in Authentication -> Users.
4. Run:
   update public.profiles set is_admin = true where email = 'YOUR_EMAIL';
5. Open config.js and paste:
   SUPABASE_URL = your project URL
   SUPABASE_KEY = your Publishable key
6. Upload ALL files from this folder to the ROOT of the GitHub repository.
7. Replace the old files when GitHub asks.
8. Open the site -> Админ.
9. Log in.
10. Edit text, forecasts, players, GI, GOAT, news and photos.
11. Click "Сохранить всё".

Important:
- Never put a service_role/secret key into config.js.
- The sample NBA data is demo data and should be replaced with your verified data.
